## English post

Introducing **Image2Editable**, an MIT-licensed agent skill for turning images, papers, and briefs into editable visual designs.

It can reconstruct a figure, design a new framework or poster, learn selected style traits from references, and extract components and palettes. The workflow keeps source analysis and actual reference images together in an image + text spec, then carries a reviewed visual target into SVG or native PPTX reconstruction.

The first gallery covers a CLIP framework, a water-cycle explainer, a product visual, and a stargazing poster. These are visual-target examples; the repo also includes an executable SVG/library fixture and records what required repair.

English and Chinese READMEs, prompts, and runtime requirements are included. Feedback on scientific accuracy, visual quality, and native editing is welcome.

Repository: https://github.com/guangzhaoli/image2editable

Attach the four-case gallery when posting.

## 中文发布文案

开源了 **Image2Editable**：一个把图片、论文和想法转成可编辑视觉设计的 Agent Skill，采用 MIT 协议。

它可以复刻论文图、根据论文内容设计框架图、生成 poster 和图文视觉，也能学习你提供的参考图，把配色、字体气质和布局用到新图或已有图上。

流程里会保存真正的图文混合 spec：参考图、局部样本、色号、文字分析放在一起。选定完整视觉目标后，再通过统一绘图 spec 重建 SVG 或原生 PPTX，并分别检查内容、视觉效果与可编辑性。

首批展示了 CLIP 框架图、水循环科普图、便携音箱图文和观星海报。四张目前是视觉稿，仓库另附可运行的 SVG／组件库示例，也保留了需要返工的过程。

中英文 README、提示词和环境依赖都整理好了，欢迎用自己的案例试试，反馈具体的科学内容、排版或可编辑性问题。
