# 使用示例

这些是调用技能的示例提示，不代表真实论文或经过实测的重建结果。

## Affinity 忠实复刻

> 使用 $image2editable，在 Affinity 中复刻 paper.pdf 第 4 页 Figure 3。优先保留原 PDF 的可编辑路径和文字；不能复用的部分先提取坐标、色板和素材，把原图作为锁定底图按 spec 原位描绘。颜色记录采样位置和 RGB/HEX。交付原生工程、PDF 和 PNG 预览，列出字体替代与不能直接编辑的区域。

## Illustrator 方法图

> 使用 $image2editable，把这张网络结构截图重建成 Adobe Illustrator 工程。所有模块名保持可编辑，检查残差连接与箭头方向；公式可保留矢量路径并附公式文本。先按原版忠实复刻，不自行换色或改布局。

## 原生工程的局部修改

> 使用 $image2editable，修改当前 Affinity 工程：把 Encoder 改成 Backbone，第三组模块改为蓝色，其余结构和尺寸保持。另存修改后的原生文件，并导出同一画板的预览。

## PowerPoint 可编辑论文图

> 使用 $image2editable，把这张论文图按当前 v2 策略复刻为 PowerPoint。保留原图比例，先提取 spec、色板和素材，再以原图为参考重建。标签用可编辑文本框，模块用原生形状，箭头和路径能分别修改。交付 PPTX、PDF 和 PNG，最终导出不包含参考底图。不要自动添加封面或改成汇报幻灯片风格。

> 使用 $image2editable，修改这个 PPTX 的第 2 页，只把 Encoder 改成 Backbone，保留其坐标、字号和连接；另存副本并检查其他区域没有变化。

## 只有截图的定量图

> 使用 $image2editable，复刻这张折线图的版式。我没有原始数据，曲线仅作明确标注的视觉近似；不要声称恢复了真实实验数据。保留刻度、单位、图例、颜色和虚实线，交付可编辑标签和路径。

如果请求改成“恢复精确实验结果和置信区间”，缺失原始数据就是实质限制，应请求数据，先处理独立的版式工作。

## 跨软件交付

> 使用 $image2editable，分别交付可在 Illustrator 和 Affinity 中继续编辑的文件。先以 Illustrator 为主工程，再测试交换到 Affinity；两个原生文件都重开检查，说明文字、公式和透明效果在两边的差异。
