# Changelog

## 4.2.1 — public packaging

- Introduce the public project and skill name **Image2Editable / image2editable**.
- Preserve the existing v4.2.1 workflow, drawing schemas, renderer, and library extraction algorithms.
- Add English and Simplified Chinese READMEs, the four English gallery cases, reusable prompt records, and MIT licensing.
- Include a portable image + text reference study and a synthetic SVG/library example.

The historical local skill name was `paper-figure-replica`. Only public identity metadata and invocation examples changed in the packaged skill. A packaging manifest records the exact file differences. Existing local installations were not overwritten.

## Existing v4.2.1 workflow baseline

- Optional reference-style learning for restyling existing images and creating new visuals.
- Image + text visual specs with actual local references, annotated regions, measured or declared palettes, HTML/JSON records, and attachment preparation.
- Existing content review, full-composition visual targets, shared figure spec, SVG/PPTX rendering, and component/palette catalogs.

The v4.2 design strategy remains the baseline. This release does not adopt the experimental v4.3 strategy or claim a new benchmark result.
